# App Store Readiness

Materials for a future iOS/Android App Store submission. **Nothing here is required for the v0.1 web app** — it ships when Orbit is wrapped natively (see `../capacitor/`). This folder is written now so the listing, privacy, and review work is ready when the native shell is built and tested.

## Status

- The web app is complete and PWA-installable today.
- The Capacitor scaffold exists (`../capacitor/`) but is **unverified** — it has not been built against Xcode/Android SDK in this environment. Do not submit until a real native build is produced and the TestFlight checklist passes.
- All copy here obeys the same claim guardrails as the marketing folder: no guaranteed friendships/dates/marriage/mental-health outcomes; not therapy, not a dating app, not an AI companion.

## Category & age at a glance

- **Category:** Lifestyle (primary), Health & Fitness (secondary — social wellbeing, *not* medical).
- **Age rating:** 17+ is unnecessary; target **4+ / 12+**. No objectionable content. The one thing to watch: never let store copy imply mental-health treatment, which could invite a stricter category.
