# Metrics Definitions

## North Star
**Weekly completed social reps** (in-app). Content exists to move this — not views.
**Secondary North Star:** follow-ups sent after real-world interactions.

## Content metrics (per asset per platform)
| Column | Definition |
|--------|-----------|
| views | Platform-reported plays/impressions |
| likes | Hearts/likes |
| saves | Saves/bookmarks — **the highest-signal content metric**; saved content converts later |
| shares | Sends/shares — the second-highest signal |
| comments | Count; note qualitative standouts in `notes` |
| profile_clicks | Platform-reported profile visits from the post |
| link_clicks | Link-in-bio clicks attributed that day (imperfect — note assumptions) |

## Funnel metrics (weekly totals)
| Metric | Source |
|--------|--------|
| landing_visits | Netlify analytics / your analytics tool |
| waitlist_signups | Email provider |
| onboarding_starts / completions | In-app (manual until analytics land) |
| seven_day_plans | Plans generated |
| events_added / people_added | In-app |
| follow_ups_generated / sent | In-app |
| weekly_reviews_completed | In-app |
| paid_intent | "I'd pay" replies + pricing-page clicks + checkout starts |

## Scoring an asset (the scorecard)
score = saves×4 + shares×3 + comments×2 + likes×1, normalized per 1k views.
- **Amplify** (make 2 more on the insight): score ≥ 2× category median
- **Keep**: within band
- **Kill theme**: category < ½ median two weeks running

## Honesty rules
- Views are entertainment; saves/shares are intent; signups are truth; reps are the product working. Never celebrate upstream numbers when downstream is flat.
- Attribution will be fuzzy. Note assumptions in the tracker rather than inventing precision.
