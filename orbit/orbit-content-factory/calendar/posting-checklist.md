# Manual Posting Checklist

## Batch workflow (Sunday, ~45 min preps the whole week)
1. Open `30-day-calendar.md` — read the coming week's rows.
2. For each video: open its folder, queue `video.mp4` + platform caption + hashtags in each app's drafts (TikTok Studio, IG, YT Studio all support scheduling).
3. For each carousel/static: queue slides/image + caption the same way.
4. Reddit/FB posts don't schedule well — set a phone reminder for the calendar's time window and post live (you need to be present for early comments anyway).
5. Check `analytics/content-tracker.csv` has rows ready for the week.

## Per-post checklist
- [ ] Native upload (never cross-post with another platform's watermark)
- [ ] Caption from THIS platform's file (`tiktok-caption.txt` ≠ `instagram-caption.txt`)
- [ ] Trending/quiet audio added in-app per `upload-notes.txt` (videos)
- [ ] Link in bio is live; pinned comment added where the package specifies
- [ ] Reddit/FB: re-read the sub/group rules TODAY (they change), use softer version if unsure
- [ ] 30 minutes of comment replies the following morning — this is non-optional; replies are the actual growth mechanism

## Weekly (Sunday, 15 min — after the batch prep)
- [ ] Fill the tracker; compute scores
- [ ] Flag ≥2× median performers → schedule 2 derivative assets (see `../repurposing/workflow.md`)
- [ ] Apply the kill rule to any category <½ median two weeks running
- [ ] Paste top/bottom performers + funnel numbers into the weekly review session (Routine will prompt you)
